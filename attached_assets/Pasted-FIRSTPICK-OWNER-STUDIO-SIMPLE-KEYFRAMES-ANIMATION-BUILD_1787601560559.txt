8. SIMPLE KEYFRAME SYSTEM

I want the keyframe system to be very simple to use.

Do NOT make it feel like professional animation software that requires complicated timelines.

The basic workflow should be:

1. Select an element, such as an image.
2. Press:

Add Scroll Animation

3. Choose where the animation starts on the page.
4. Choose where the animation ends on the page.
5. Position the element at the START.
6. Position the element at the END.
7. FirstPick automatically animates smoothly between those two states while the customer scrolls.

That is the main workflow.

⸻

9. SIMPLE START AND END POINTS

For example, I add a backpack image.

I select:

Start Here

Then place the backpack where I want it to begin.

Then I scroll to another point on the page and press:

End Here

Then move the backpack where I want it to finish.

FirstPick automatically creates the movement between those two positions.

Example:

START:
Backpack centered.

END:
Backpack moved to the right and slightly larger.

As the customer scrolls from the Start marker to the End marker, the backpack smoothly moves from Start → End.
