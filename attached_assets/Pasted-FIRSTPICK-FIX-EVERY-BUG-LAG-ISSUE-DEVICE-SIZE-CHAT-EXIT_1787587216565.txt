11. CHAT — LET ME EXIT

When I enter an admin chat, I need an obvious way to leave it.

Add a clear:

Back

or

Close Chat

button.

On mobile, it should take me back to the conversation list.

On tablet/desktop, it should either:

* Close the active conversation panel
* Return to the chat list
* Restore the previous layout

Do not trap the admin inside a conversation.

⸻

12. CHAT EXIT BEHAVIOR

Make chat navigation predictable.

Example:

Chats → Ahmed → Back → Chats

or:

Chats → FirstPick Admin Group → Back → Chats

If a chat is opened from an admin profile, the Back button should return to the appropriate previous screen.

Do not reset the entire Admin Dashboard just to leave a conversation.

⸻

13. SWIPE BACK WHERE APPROPRIATE

On touch devices, support natural navigation where the framework safely allows it.

For example:

* Swipe back from private chat to chat list
* Browser back should not break the app
* Back navigation should preserve chat state where reasonable

Do not interfere with native browser gestures unnecessarily.

15. CHAT SCROLLING

Make chat scrolling smooth.

Fix:

* Jumping to wrong message
* Scroll position resetting
* New messages forcing unwanted scroll
* Keyboard opening and breaking scroll
* Old-message loading lag
* Duplicate rendering

If the user is already near the bottom, new messages can keep them at the bottom.

If they are reading older messages, do not aggressively yank them downward.
